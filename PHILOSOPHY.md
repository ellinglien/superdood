# Superdood: design philosophy

A journal for handwriting, drawing and doodling: fun and useful, and now and
then slightly mischievous. The tools aim to be **useful but delightfully
unpredictable**.

Few, clear tools. Limits are the point: they keep drawing creative and
spare the artist decision fatigue.

1. **Each tool has one obvious behavior.** No modes, toggles or hidden state
   that change what a tool does. A different behavior is a different tool.
2. **Fix values instead of adding settings.** Pick a good default and keep
   it. When a choice is unavoidable, offer a few presets, never a slider or
   a settings screen. The aim is minimal, not a fixed count.
   One exception, the owner's own decision (2026-10-24): the drawing screen's
   brush size is a slider ("I find myself wanting to fine tune the size
   often. a slider with a preview would be ideal"). It replaced the four size
   presets there, so it is still one control, not one more.
   A second one (the owner, 2026-11-04): **System Settings**, one small
   screen from the menu ("can we add system settings? this would be a new
   section to adjust a few things (defaults, etc)"). It holds how the app
   behaves everywhere, never what a tool does: Automatic Refresh ("i find
   the frequency of screen flashes to be a bit much") and the touch
   controls ("customize the touch controls (2 finger tap, etc)"). Few rows,
   each On and Off or a few chips; it stays that small.
3. **Nothing asks for a decision while drawing.** Drawings name and save
   themselves. Copies (PDF, PNG) are made only when asked, with Export Now
   (the owner, 2026-10-24: "export only when you need it").
4. **What you draw stays put, unless the tool says otherwise.** Ordinary
   marks change only while the pen works them (wet watercolor, for its few
   seconds), then set. The unpredictable ones (Mold, gravity, Float, fading
   ink) are opt-in tools that say what they do, never a surprise in a
   plain pen.
5. **Behave like physical media.** Pressure, tilt and speed do what they
   would with a real pen, brush or eraser, so the hand already knows the
   tools.
   **The hand decides** (the owner, 2026-10-31): when two brushes differ by
   one dial and a real medium would do both, it is one brush, and pressure,
   tilt or where you start picks between them (Press to Push, Fill in's
   loops), never a second brush or a toggle.
6. **Black, white and grey.** No color.
7. **Every new feature must pass the test:** would the app feel worse
   without it? If not, leave it out. Removing something is as good a change
   as adding something.

When in doubt, choose the version with fewer buttons.

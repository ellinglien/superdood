Install Superdood

  1. On the Supernote: Settings → Security & Privacy → turn on Sideloading.
  2. Plug the Supernote into this computer with its USB cable.
  3. Click Install Superdood, pick the Supernote in the box that opens, and tap Allow on the Supernote if it asks.

Use a Chrome-based or Edge browser on a desktop computer to install. Any existing notebooks are preserved when you update. For other install methods check the README.
